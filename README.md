# Apple design skills for Claude Code

A [Claude Code](https://claude.com/claude-code) skill for building Apple-style web UIs.

| Skill | For |
|---|---|
| `skills/apple-web-design` | Web apps / PWAs (plain HTML, CSS, JS): Apple.com + iOS 26 look, Liquid Glass, motion |


## Install

```bash
git clone https://github.com/JT-GRDT/apple-design-skills
cp -r apple-design-skills/skills/* ~/.claude/skills/
```

On Windows copy into `C:\Users\<you>\.claude\skills\`. Restart Claude Code.
